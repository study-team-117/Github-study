# AWS入門｜Amazon RekognitionとCustom Labels

[← 教材トップ](../../README.md)

写真から「何が写っているか」を判定するAWSのサービスを、文房具の仕分けを題材に紹介します。この資料はAWSアカウントなしで読めます。実際の環境構築・モデル学習・推論は、情報システム工学科3年春の授業で取り組んでください。

## 1. AWSとは

AWS（Amazon Web Services）は、サーバーやデータの保存場所、画像分析などの機能をインターネット経由で使えるクラウドサービスです。たとえば、自分でサーバーを購入して設置する代わりに、必要なときにAWS上で仮想サーバーを用意できます。

| サービス | 何に使うか | 文房具の仕分けアプリでの例 |
| --- | --- | --- |
| Amazon EC2 | 仮想サーバーでプログラムを動かす | 写真を受け取るWebアプリを動かす |
| Amazon S3 | ファイルを保存する | 仕分けに使う写真を保存する |
| Amazon Rekognition | 画像や動画を分析する | 写真に写った文房具を判定する |

アプリは、写真を保存する処理をS3に、画像を分析する処理をRekognitionに任せられます。この後は、その中の画像分析に注目します。

[参考：AWSとは](https://aws.amazon.com/jp/what-is-aws/)

## 2. Amazon Rekognitionとは

Amazon Rekognitionは、画像や動画から情報を取り出すAWSのサービスです。ここでは画像のラベル検出に絞ります。ラベルとは、画像の内容を表す名前です。

| 機能 | どんなときに使うか | 文房具の例 |
| --- | --- | --- |
| ラベル検出（`DetectLabels`） | AWSが用意した一般的なラベルで写真を分類したい | 写真に文房具や机などが写っているかを確認する |
| Custom Labels（`DetectCustomLabels`） | 自分の用途で決めた分類や対象を検出したい | 「リングノート」「方眼ノート」など、自分で決めた種類を見分ける |

既成のラベルで目的を満たせるかをまず確かめます。必要な分類が得られないときは、Custom Labelsで画像と正解ラベルを用意して、専用のモデルを学習します。

[Amazon Rekognitionのラベル検出](https://docs.aws.amazon.com/ja_jp/rekognition/latest/dg/labels.html) ｜ [Amazon Rekognition Custom Labels](https://aws.amazon.com/jp/rekognition/custom-labels/)

## 3. Custom Labelsでモデルを作る流れ

1. **判定したいものを決める。** 写真全体を種類に分けたいなら画像分類を使います。複数の商品が写った写真から位置も知りたいなら、物体検出を使い、対象を囲む枠（バウンディングボックス）を付けます。
2. **画像に正解を付ける。** たとえば「リングノート」と「方眼ノート」は特徴が重なり得ます。「リングあり」「リングなし」のように、分類の目的に沿って判断基準を決めます。明るさや背景、撮影角度も変えて画像を集めます。
3. **学習用と評価用を分ける。** 同じ写真や、ほぼ同じ連写画像が両方に入ると、未知の画像に対する性能を測りにくくなります。撮影した商品や撮影回ごとに分ける方法があります。
4. **学習して結果を評価する。** 適合率は「そのラベルと判定した画像のうち、実際に正しかった割合」、再現率は「そのラベルが正解の画像のうち、見つけられた割合」です。数字に加えて、具体的にどんな画像を誤判定したか見ます。
5. **授業で推論を試す。** モデルを起動し、学習に使っていない画像を入力して確認します。使い終わったらモデルを停止します。

[Custom Labelsの開発者ガイド](https://docs.aws.amazon.com/rekognition/latest/customlabels-dg/what-is.html)

## 4. 授業前のミニ演習

> AWS上でモデルを学習・実行すると料金が発生する場合があるため、今回はAWSを使った実習や個別の操作サポートは行いません。このミニ演習はAWSアカウントなしで取り組めます。

次は、リングあり／なしを分類した**架空の結果**です。AWSを使わずに、表だけで考えてみましょう。

| 写真 | 正解 | モデルの判定 |
| --- | --- | --- |
| A：表紙とリングが写っている | リングあり | リングあり |
| B：リングの部分が机の影に入っている | リングあり | リングなし |
| C：リングのない表紙に丸い模様がある | リングなし | リングあり |
| D：無地の表紙が写っている | リングなし | リングなし |

1. 「リングあり」の適合率と再現率は何％ですか。
2. BとCの誤判定を減らすために、どんな写真を学習用データに加えますか。

<details>
<summary>回答例</summary>

1. 「リングあり」と判定したA・Cのうち正解はAだけなので、適合率は1÷2＝50％です。実際に「リングあり」のA・Bのうち見つかったのもAだけなので、再現率も50％です。
2. Bにはリングが暗く写った写真や、角度によって目立ちにくい写真を加えます。Cには丸い模様があるリングなしの写真を加えます。似た条件の別の写真を評価に使い、改善したか確かめます。

</details>

## 5. 料金が発生する箇所

- **一般の画像ラベル検出**では、主に処理した画像の枚数に応じて料金が決まります。
- **Custom Labels**では、主にモデルの学習に使った時間と、推論できる状態でモデルを稼働させた時間が課金対象です。起動中は画像を送っていない時間も費用がかかり得ます。
- 画像をAmazon S3に保存する場合は、保存容量やリクエストなどの料金も確認します。モデルを停止しても、残っているS3のデータは別に扱われます。

無料枠やクレジットは、サービス・アカウント・期間で適用条件が異なります。実習前に、授業で使うアカウントとリージョンの料金を確認してください。

[Amazon Rekognitionの料金](https://aws.amazon.com/jp/rekognition/pricing/) ｜ [Amazon S3の料金](https://aws.amazon.com/jp/s3/pricing/)
