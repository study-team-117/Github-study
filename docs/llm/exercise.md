# LLMアプリの設計｜ミニ演習

[← LLM入門](README.md) ｜ [← 教材トップ](../../README.md#補足教材) ｜ [AIの使い方の共通方針](../../README.md#学習と開発でのaiの使い方)

LLMの代わりに自分で教材を検索し、回答と出典を組み立てます。メモ帳などに「質問・根拠・回答」の順で記録します。

1. 「`git add .` をするとGitHubに反映されますか？」に答えます。[Git基本操作](../01-basic.md)から根拠を1箇所選び、結論、補足、出典を書きます。
2. 「注文がない商品をSQLで探すには？」に答えます。[SQL入門](../sql/README.md)のサンプルに合うSQLと、結果に表示される商品名を書きます。出典も添えます。
3. 「来年度の課題の提出期限はいつですか？」と聞かれました。教材の情報だけで答えられるか判断し、利用者に返す文を書きます。

## 追加課題：検索と失敗時の動作を設計する

4. 「コミットする前に、選んだ変更だけ外したい」という質問を読み、検索に使うキーワードを3つ書きます。[04章のトラブル対処](../04-troubleshooting.md)で根拠となる節を探し、検索に失敗したときに尋ねる確認質問も1つ用意します。
5. 「正しい教材が見つかった質問」と「正しい回答が返った質問」を区別できる評価表を作ります。課題1〜4の質問に対して、期待する回答・参照先・避けたい誤りを1行ずつ書きます。

## 発展：レビューする

ペアで回答を交換します。「結論が正しいか」「出典が結論を支えているか」「根拠のない情報が含まれていないか」を確認し、修正が必要な箇所を1つ伝えます。
