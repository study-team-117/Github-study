# データベースの基礎と実践｜補足教材

[← 教材トップ](../../README.md#補足教材)

文房具店の商品と注文明細を使い、DBの選び方、設計、アプリからの利用、チームでの構造変更を学びます。読み進める順番は次のとおりです。開発中は、必要な章だけ参照できます。

| 章 | 学ぶこと | 目安 |
|---|---|---:|
| [01 データベースの基礎](01-basics.md) | ファイル管理との違いとDBの選び方 | 12〜15分 |
| [02 データベース設計](02-design.md) | キー、ER図、正規化、インデックス | 20〜25分 |
| [03 SQLの基本](03-sql.md) | SQLの用途と実行例 | 20〜25分 |
| [04 アプリケーションとの連携](04-application.md) | API、ORM、PythonとSQLite、トランザクション | 20〜30分 |
| [05 チーム開発とデータベース管理](05-team.md) | マイグレーション、シーダー、PRでの共有 | 20〜25分 |
| [06 データベースのセキュリティ](06-security.md) | パラメータ化、権限、バックアップ | 15〜20分 |

**必修**は各章の中心、**推奨**は実際の開発で役立つ補足、**発展**は必要なときに開く内容です。SQLから始めたい場合は03章と基本演習、アプリの開発を始める場合は04〜06章も参照してください。

全章の共通データは、既存の [`sample.sql`](../sql/sample.sql) にある `products`（商品）と `order_items`（注文明細）です。商品はノート、ペン、マグカップの3件です。SQLは[ブラウザ上のSQLite](../sql/README.md#準備ブラウザでsqliteを開く)でも試せます。04・05章の例はPython 3と標準ライブラリの `sqlite3`、または該当箇所に記載したSQLite CLIを使います。外部アカウントや有料サービスは不要です。
