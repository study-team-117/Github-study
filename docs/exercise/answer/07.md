## 基本演習

### 課題1：rebaseで作業ブランチの起点を更新する

準備を終えた `main` から、作業ブランチを作ります。

```bash
git switch -c practice/guide
```

`guide.md` を作成して保存し、コミットします。

```bash
git add guide.md
git commit -m "Add practice guide"
git switch main
```

`README.md` に1行追記して保存し、コミットします。

```bash
git add README.md
git commit -m "Update practice README"
git log --oneline --graph --all
```

履歴が分岐していることを確認し、`Add practice guide` の短いコミットIDを控えます。

```bash
git switch practice/guide
git status
```

未コミットの変更がなければ、次を実行します。

```bash
git rebase main
git log --oneline --graph --all
```

新しい順に `Add practice guide`、`Update practice README`、`Add practice README` が並びます。ガイドのコミットIDが変わり、`main` は `Update practice README` を指したままです。

## 応用演習

### 課題2：cherry-pickで1件だけ取り込む

`practice/guide` で `memo.md` を作成して保存し、次を実行します。

```bash
git add memo.md
git commit -m "Add personal memo"
git log --oneline -2
git switch main
git switch -c practice/pick-guide
```

履歴の2行目に表示された `Add practice guide` のIDを使います。下の `abc1234` は表示された実際のIDに置き換えます。

```bash
git cherry-pick abc1234
git log --oneline -2
git status
```

`Add practice guide` が履歴の先頭にあり、ファイル一覧には `guide.md` が表示されます。`Add personal memo` はこのブランチの履歴に含まれず、`memo.md` も表示されません。

## 発展演習

### worktreeで2つのブランチを別フォルダに開く

元のフォルダで `git worktree add ../git-advanced-guide practice/guide` と `git worktree list` を実行します。一覧には元のパスに `[practice/pick-guide]`、追加したパスに `[practice/guide]` が表示されます。

追加したフォルダには `guide.md` と `memo.md` の両方があり、元のフォルダには `guide.md` だけがあります。確認後に `git worktree remove ../git-advanced-guide` を実行し、`git worktree list` で元のフォルダだけになったことを確認します。フォルダを外しても `practice/guide` ブランチは残ります。

**考えてみようの回答例**　作業ブランチのコミットを新しい起点に積み直すときは `git rebase`、選んだコミットの変更だけを取り込むときは `git cherry-pick` を使います。
