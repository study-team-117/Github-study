## 基本演習

### 課題1：ステージだけを取り消す

`practice.md` に一時メモを追記して保存し、次を実行します。

```bash
git add practice.md
git status
git restore --staged practice.md
git status
git diff -- practice.md
```

最初の `git status` では `Changes to be committed`、ステージを外した後は `Changes not staged for commit` に `practice.md` が表示されます。`git diff` に一時メモの行が `+` 付きで表示されれば、ファイルの編集内容は残っています。

VSCodeで一時メモの行だけを削除して保存します。`git status` に `nothing to commit, working tree clean` と表示されたら次に進めます。

## 応用演習

### 課題2：同じ行を変更して競合を解消する

```bash
git switch -c practice/conflict
```

VSCodeで最初の行を「確認方法：VSCodeで差分を見る」に置き換えて保存します。

```bash
git add practice.md
git commit -m "Describe VSCode check"
git switch main
```

`main` で同じ行を「確認方法：ターミナルで状態を見る」に置き換えて保存します。

```bash
git add practice.md
git commit -m "Describe terminal check"
git merge practice/conflict
```

`CONFLICT (content)` が出たら `git status` を実行します。`Unmerged paths` に `practice.md` が出ます。ファイルを開くと、たとえば次のようになっています。

```text
<<<<<<< HEAD
確認方法：ターミナルで状態を見る
=======
確認方法：VSCodeで差分を見る
>>>>>>> practice/conflict
```

このブロック全体を「確認方法：ターミナルで状態を見て、VSCodeで差分を見る」の1行に置き換えます。区切り記号も取り除いて保存します。

```bash
git add practice.md
git merge --continue
git status
```

コミットメッセージの編集画面が開いた場合は、保存して閉じます。`git status` で `On branch main` と `nothing to commit, working tree clean` を確認し、ファイルにまとめた1行があることを確認します。

## 発展演習

### コミット済みの変更を打ち消す

末尾に「取り消し練習の行」を追記して保存します。

```bash
git add practice.md
git commit -m "Add temporary line"
git log --oneline -3
```

履歴の先頭が、自分で作った `Add temporary line` であることを確認してから、次を実行します。`HEAD` は現在の先頭コミットです。

```bash
git revert --no-edit HEAD
git log --oneline -3
git status
```

`--no-edit` は、Gitが用意したコミットメッセージをそのまま使う指定です。履歴の先頭に `Revert "Add temporary line"`、その次に `Add temporary line` が表示されます。ファイルを開き、追記行が消えて課題2の「確認方法」が残っていることを確認します。
