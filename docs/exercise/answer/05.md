## 基本演習

### 課題1：差分を見て、必要な変更だけをコミットする

2ファイルを編集して保存したら、次を実行します。

```bash
git status -sb
git diff
```

短い状態表示では2ファイルとも右側の列に `M` が表示されます。差分の本文では、追加した行に `+` が付きます。

```bash
git add README.md
git diff --staged
git diff
```

`git diff --staged` に `README.md`、`git diff` に `notes.md` の追記が表示されます。意図したファイルだけがステージされていたらコミットします。

```bash
git commit -m "Update practice README"
git show --stat HEAD
```

最新のコミットには `README.md` だけが表示されます。`notes.md` の追記は作業フォルダに残っています。

## 応用演習

### 課題2：作業メモを一時退避して戻す

```bash
git stash push -m "作業メモの途中"
git stash list
git status
```

一覧の先頭が `stash@{0}: On main: 作業メモの途中` で、`git status` に未コミットの変更がないと表示されることを確認します。それから今回の退避を戻します。

```bash
git stash pop
git stash list
git diff -- notes.md
```

追記が戻り、今回の退避が一覧から消えます。内容を確認してから記録します。

```bash
git add notes.md
git commit -m "Update practice notes"
git log --oneline -3
```

上から `Update practice notes`、`Update practice README`、`Add practice files` の順に表示されます。

## 発展演習

### ローカル専用のファイルを除外する

`.gitignore` に次の1行を書いて保存します。

```gitignore
local-notes.txt
```

```bash
git status --short
git add .gitignore
git commit -m "Ignore local practice notes"
git status --short --ignored
```

最初の状態表示には `?? .gitignore` だけが出ます。最後に `!! local-notes.txt` と表示されれば、ファイルがPCに残ったままGitの対象から除外されています。

**考えてみようの回答例**　すでに追跡しているファイルは、`.gitignore` に追加しただけでは追跡が続きます。過去のコミットにもファイルの内容は残ります。
