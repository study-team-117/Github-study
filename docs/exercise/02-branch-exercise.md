## 事前準備

[事前準備資料](../00-install.md)に沿ってGitの初期設定を済ませ、下の手順で練習環境を作ります。前の演習の状態を使う場合は、各課題の準備欄に記載しています。

ファイル編集はPC上のエディターで行います。VSCodeを推奨しますが、使い慣れたエディターでも構いません。Gitコマンドを練習する課題ではターミナルを使い、PR・レビュー・Issues・ActionsなどのGitHubの機能はブラウザで操作します。

[02章以降でPCを使う理由](../01-basic.md#ブラウザ編集とローカル編集の使い分け)

課題ごとにREADMEだけを記録した `main` から始めます。演習1・3は、新規の空フォルダで [`git init -b main`](../00-install.md#5-2-初期ブランチ名を設定する任意) を実行し、READMEを最初のコミットに記録すれば準備できます。演習2はGitHubでREADME付きの練習リポジトリを作り、PCにクローンします。

実際のプロジェクトや教材本体で作業したり、共有済みの履歴を書き換えたりしないでください。

## 演習1：作業用ブランチに変更を記録する

**使用環境**　PC上のエディターとターミナルを使います。GitHubへの接続は不要です。

### 準備

PC上のエディターで練習用フォルダを開きます。現在のブランチが `main` で、README以外の変更がなければ準備完了です。比較用に、現在の `main` のコミットIDを控えます。

### ここから演習

**初期状態**　練習リポジトリの `main` は更新済みで、未記録の変更はありません。

**課題**　`practice/outline` を作業先として用意し、`outline.md` に「学習の流れ」と1行書いて、そのブランチの変更履歴に残してください。

**達成条件**　作業用ブランチにファイルと履歴がある。`main` の内容と履歴は演習前と同じ。

## 演習2：未記録の下書きを別ブランチで共有する

**使用環境**　PC上のエディターとターミナルで作業し、共有したブランチと `main` はGitHubのブラウザで確認します。

### 準備

1. クローンした練習用フォルダをPC上のエディターで開きます。
2. `main` のまま `draft.md` を作り、「# 下書き」と書いて保存します。履歴には追加しません。
3. GitHub側にも下書きがないことを確認し、手元とGitHubの `main` の開始時のコミットIDを控えます。

### ここから演習

**初期状態**　`main` を開いたまま、まだ履歴に記録していない `draft.md` を作ってしまいました。GitHubにも下書きはありません。

**課題**　チームが下書きを読める作業用ブランチをGitHubに用意してください。PCとGitHubの `main` は元の状態を保ちます。

**達成条件**　GitHubの作業用ブランチで下書きを読める。PCとGitHubの `main` は演習前と同じコミットを指している。

## 演習3：最新の案内と共有したいガイドだけをそろえる

**使用環境**　PCで作業し、GitHubへの接続は不要です。必要なファイルを選び、比較結果を示せる方法なら、エディターの差分表示とターミナルを使い分けて構いません。

### 準備

1. READMEだけを記録した `main` で、`git switch -c practice/draft` を実行します。
2. `guide.md` に「# 学習ガイド」、`notes.md` に「# 未承認メモ」と書き、両方を下書きブランチにコミットします。
3. `git switch main` で戻り、READMEに「集合は15時」と追記してコミットします。準備はここで止め、両ブランチを残します。

### ここから演習

**初期状態**　古い `main` から分けた `practice/draft` に、共有したい `guide.md` と未承認の `notes.md` が記録されています。その後 `main` では `README.md` の案内が更新されました。

**課題**　最新の案内を含む `main` を土台に、下書きから `guide.md` の内容を選んで `practice/preview` に取り込んでください。`main` と元の下書きブランチを変更せず、未承認のメモは下書きブランチに残します。

**達成条件**　`practice/preview` は最新の `main` を含み、比較した差分は `guide.md` だけ。元のブランチではメモも読める。
