# 03 チーム開発の基本｜ミニ演習

> **目安：15〜20分** ｜ **形式：個人またはペア**
>
> 作業用ブランチの変更をPull Request（PR）で提案し、差分を確認してから `main` にマージします。最後にPCの `main` を更新します。

[← 03章の解説に戻る](../03-team.md) ｜ [← 教材の目次に戻る](../../README.md#目次)

## 事前準備

- [02章の演習](02.md)で `feature/branch-practice` をpushした、自分の練習用リポジトリ `git-practice` を使います。PC側は `git status` で未コミットの変更がないことを確認します。
- 02章の演習をスキップした場合は、[03章の「作業ブランチで変更を作る」](../03-team.md#3-3-作業ブランチで変更を作る)で `docs/add-team-note` をpushし、以降のブランチ名を `docs/add-team-note`、確認するファイル名を `team-note.md` に読み替えます。
- ペアで取り組む場合は、相手が対象リポジトリを閲覧してレビューできることと、誰がマージするかを先に確認します。

## 課題1：Pull Requestを作る

1. GitHubで自分の `git-practice` を開き、**Pull requests → New pull request** を選びます。
2. 取り込み先の **base** に `main`、変更元の **compare** に `feature/branch-practice` を選びます。
3. 差分に `branch-practice.md` が含まれていることを確認します。
4. タイトルに「ブランチ演習のメモを追加」と入力し、説明欄に「何を変更したか」「どう確認したか」を1行ずつ書いてPRを作成します。PR番号と **Open** の表示を確認します。

## 課題2：差分を確認してマージする

1. PRの **Files changed** を開き、意図したファイルと内容だけが含まれていることを確認します。
2. ペアの場合は、**Reviewers** から相手に依頼します。相手は差分を確認し、確認した点や気になった点をレビューで伝えます。個人の場合は、自分で確認した点をPRのコメントに1行書きます。
3. 修正を依頼された場合は、同じ作業用ブランチで修正をコミットしてpushし、PRの差分が更新されたことを確認します。
4. 発展課題にも取り組む場合は、ここで下の発展課題へ進みます。確認が終わったら、PRをマージして **Merged** の表示を確認します。GitHubのファイル一覧で `main` を選び、`branch-practice.md` があることを確認します。

マージボタンが押せない場合は、PR画面に表示される理由を確認します。承認、テスト、権限、競合については[03章のトラブル対処](../03-team.md#3-9-よくあるトラブル)を参照してください。

## 課題3：PCのmainを更新する

1. VSCodeのターミナルで `git status` を実行し、未コミットの変更がないことを確認します。
2. `main` に切り替え、GitHub上でマージした変更を取り込みます。

   ```bash
   git switch main
   git pull --ff-only
   ```

3. VSCodeで `branch-practice.md` を開き、GitHub上で確認した内容と同じか確認します。

## 完了チェック

- [ ] `base: main` と `compare: feature/branch-practice` を確認してPRを作成した。
- [ ] 差分を確認し、PRが **Merged** になった。
- [ ] GitHubとPCの両方で、`main` に演習のファイルがあることを確認した。

## 発展課題：同じPRに修正を反映する（任意・5〜10分）

**課題2でマージする前**に取り組みます。

1. PRの差分を読み、`branch-practice.md` に補足が必要な箇所を1つ選びます。たとえば、ブランチを切り替えて確認したことを追記します。
2. PCで作業用ブランチに切り替え、ファイルを編集します。`git status` で対象を確認し、`git add branch-practice.md` → `git commit -m "Clarify branch practice note"` → `git push` の順に実行します。別のファイルで進めている場合は、ファイル名を読み替えます。
3. 元のPRを再読み込みし、PR番号が同じで、**Files changed** に追記が表示されることを確認します。その後、課題2のマージに進みます。

**考えてみよう**　作業用ブランチへのpush、PRのマージ、PCでのpullは、それぞれどこを更新する操作でしょうか。
