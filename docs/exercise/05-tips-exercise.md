## 事前準備

[事前準備資料](../00-install.md)に沿ってGitの初期設定を済ませ、下の手順で練習環境を作ります。前の演習の状態を使う場合は、各課題の準備欄に記載しています。

ファイル編集はPC上のエディターで行います。VSCodeを推奨しますが、使い慣れたエディターでも構いません。Gitコマンドを練習する課題ではターミナルを使い、PR・レビュー・Issues・ActionsなどのGitHubの機能はブラウザで操作します。

GitHubへの接続は不要です。課題ごとに空のフォルダをPC上のエディターで開きます。基本・応用では `git init -b main` で練習用リポジトリを用意します。発展の準備欄には、Bashで初期状態を作る例があります。

実際のプロジェクトや教材本体で作業したり、共有済みの履歴を書き換えたりしないでください。

## 基本演習

### 必要な差分だけを記録する

**使用環境**　PCのエディターとターミナルを使います。差分と履歴はターミナルで確認します。

#### 準備

1. `README.md` に「# 案内」、`notes.md` に「# 作業メモ」と書き、最初のコミットに記録します。
2. READMEに「案内を更新しました。」、メモに「このメモは編集中です。」と追記します。2ファイルを保存したら、まだ履歴に入れずに止めます。

#### ここから演習

**初期状態**　`README.md` に案内の修正、`notes.md` に編集中のメモがあります。どちらも未記録です。

**課題**　案内の修正だけを履歴に残してください。

**達成条件**　最新の履歴に案内だけがあり、メモは手元に残っていることを差分で示せる。

## 応用演習

### 急ぎの修正を分けて作業を再開する

**使用環境**　PCのエディターとターミナルを使います。作業の分離と再開に使うGit操作はターミナルで行います。

#### 準備

1. `main` のREADMEに「閲覧リンクを共用」と書き、最初のコミットに記録します。
2. `git switch -c practice/guide` で作業ブランチに移ります。README末尾に「# ガイド（執筆中）」を追記して保存し、未記録のまま止めます。

#### ここから演習

**初期状態**　`practice/guide` で、READMEにガイドを書き足している途中です。`main` のREADMEには「閲覧リンクを共用」と書かれており、「共有」に直す急ぎの依頼が来ました。

**課題**　ガイドを保ったまま、誤記だけを別のブランチ `fix/readme-wording` に記録してください。

**達成条件**　修正ブランチには誤記の訂正だけがあり、元の作業ブランチには書きかけのガイドが残る。

## 発展演習

### 退避した作業から必要な1件を復元する

**使用環境**　PCで作業します。退避内容と復元結果を説明できる方法なら、ターミナルとエディターの差分表示を組み合わせて構いません。準備欄のコマンドを実行する場合はBashを使います。

#### 準備

空のフォルダでBashを開きます。WindowsではGit Bashを使えます。以下を上から実行します。準備では、2件分の作業を履歴とは別に保管し、再開先の見出しを整えます。

```bash
git init -b main
printf '# ガイド\n\n## 作業\n\n下書き本文\n' > guide.md
git add guide.md
git commit -m "Add guide"
printf '\nレビュー待ちの確認方法：担当者の返信を確認する。\n' >> guide.md
git stash push -m "メモA"
printf '\n発表の練習：資料を声に出して読む。\n' >> guide.md
git stash push -m "メモB"
git switch -c practice/resume
printf '# チームガイド\n\n## 作業\n\n下書き本文\n' > guide.md
git add guide.md
git commit -m "Clarify the guide title"
```

`practice/resume` に切り替わり、`guide.md` の見出しが「チームガイド」になっていれば準備完了です。どちらの記録を復元するかは、ここから考えます。

#### ここから演習

**初期状態**　退避した作業が2件あり、どちらも `guide.md` を編集しています。必要なのは「レビュー待ちの確認方法」を書いた方です。再開先 `practice/resume` には、別のメンバーによる見出しの修正が記録されています。

**課題**　内容を調べて必要な作業だけを `practice/resume` に復元し、既存の見出し修正ともう1件の退避を保ってください。

**達成条件**　復元先に必要な追記と修正済みの見出しがある。不要な追記がなく、もう1件の退避は残る。復元前に見た差分を説明できる。
